# Revision 5 artwork

23 distinct editorial illustrations generated with the built-in image generation tool, one per email. Each `<id>-master.png` has a matching optimized `<id>.jpg`. The exact complete prompt for each is in `prompts.json`; active consumers, dimensions and SHA-256 hashes are in `../manifest.json`.

All share orange studio backgrounds, white sculptural objects, soft lighting and orange accents. These are editorial metaphors, not scientific evidence, real customer records or product photography. Source masters are preserved; JPEGs are resized/compressed only. Prior revision images are retired from the build.
